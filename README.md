# Description:

**Problem:**
Create a front-end website that allows users to view, search, and filter books from an external API.

**Solution:**
A simple web app that fetches book data from an API, displays it, and provides search and filter functionality.

**Special Features:**

1. Pagination for browsing results;
2. Responsive Design;

# Tech Stack:

**Languages:** HTML, CSS, JavaScript
**Framework / Libraries:** none
**Other Tools:** Github; API.

# Features:

1. Search books from external API;
2. Filter books based on Author, Title;
3. Pagination for browsing multiple pages.
